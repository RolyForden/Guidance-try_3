## 2. 链路
| 输入 | 模块 | 输出/职责 |
|---|---|---|
| RGB/原问题，训练时另有QA与目标mask | 数据/预处理 | 图像张量、tokens、坐标元数据；GT只入损失/离线评分 |
| RGB | CLIP整体路径、SAM Hiera细节路径 | 整体语义与高分辨率视觉特征 |
| 双路视觉特征 | MPA | 融合视觉tokens，连接语义与细节 |
| 融合视觉tokens、问题 | 语言主干/分割token投影 | 文本与分割提示；实际生成路径待核 |
| 提示、多尺度图像特征 | HRD | 逐尺度mask及还原到原图的logits |
| 训练QA/GT mask | CE、BCE、Dice | 文本与像素监督；训练配置待核 |
| 预测logits、独立GT | evaluator | gIoU/cIoU、每样本输出；不得让GT回答反向进入模型 |

## 3. 口径
- 原论文参照模型与数字见队友[解读](../../PixDLM_研究调研与候选计划_2026-10-08(1)/01_PixDLM解读与版本核验.md)，不是本地复现。

- 官方元数据报告2999/2000/5001；独立原图/场景分组及重复项尚待解包核验，不推定数据独立。

## 4. 关键设计的 why
| 设计 | 动机及原文证据 |
|---|---|
| 双路与MPA | 整体语义和细节分辨率的互补；原文Table 3研究融合，不能归因为关系混绑 |
| 三尺度HRD | 恢复细粒度mask；Table 4两尺度56.43/58.01到三尺度62.35/63.23，均是作者数字 |
| 文本推理与分割监督 | 支持隐式任务；推理文本的来源/可部署性必须与GT回答条件分离 |

## 5. 限制
- 原文已覆盖小目标、密集场景和空间问题；尚无原文证据证明“关系理解正确但实例绑定失败”是主要残余限制。
- 公开评测回答条件分支是评测口径问题，不直接构成P1的问题级gap。
- P1候选限制：参照可见且唯一、同类实例密集时选错邻居；必须由干净基线输出补证，目前未证实。

## 5b. 盲区条件候选
| 条件 | 待检验假设/公开数据 |
|---|---|
| 可辨参照关系+同类多实例 | 单目标提示未保留角色对应；DRSeg是否有足够无歧义样本待审 |
| 原问题-only、无标注回答输入 | 公开条件分支掩盖部署输入难度；DRSeg validation可检查，非新颖性主张 |
| 跨视角的方向/参照歧义 | 单图二维信息可能不足；DRSeg样本是否可确定待审，不自造3D标签 |
