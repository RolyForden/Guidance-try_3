# P1-参照关系绑定

## 当前问题

验证 PixDLM 在同类密集、参照关系可辨的 DRSeg 图像中是否存在目标实例混绑，以及简单位置提示是否足以解决。先补齐底座与实证锚，不承诺双角色模块有效。

## 当前判断

- 已知：用户选择优先验证 P1；公开评测分支存在标注回答条件输入，不能直接作为问题-only基线。
- 未知：底座复现量级、真实混绑频率、简单对照收益。
- 放弃条件：可靠基线不支持混绑假设，或匹配简单对照消除主要问题时，暂停本版参照绑定提案；不外推否定所有关系方法。
- 当前状态（2026-10-10训练前准备）：两处txt_feat修复及question-only适配器10项CPU工程回归通过。DRSeg仅train/val已解包到数据盘，2999/2000条记录的图像路径、唯一ID及问答长度核验通过，两split的ID交集为0；test未解包或读取内容。官方训练脚本使用LLaVA-v1.6-vicuna-7b初始化，不可用全DRSeg微调后的PixDLM权重做20%训练起点；已固定该初始化版本并开始下载三片权重，尚未完成。运行依赖、生成hidden_states对齐、真实模型加载及正式训练协议仍待完成，未训练或评测。
