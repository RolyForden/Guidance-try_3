# P1-参照关系绑定

## 当前问题

验证 PixDLM 在同类密集、参照关系可辨的 DRSeg 图像中是否存在目标实例混绑，以及简单位置提示是否足以解决。先补齐底座与实证锚，不承诺双角色模块有效。

## 当前判断

- 已知：用户选择优先验证 P1；公开评测分支存在标注回答条件输入，不能直接作为问题-only基线。
- 未知：底座复现量级、真实混绑频率、简单对照收益。
- 放弃条件：可靠基线不支持混绑假设，或匹配简单对照消除主要问题时，暂停本版参照绑定提案；不外推否定所有关系方法。
- 当前状态（2026-10-10开跑核查）：用户授权开始实验；GPU已恢复，bf16及小型CUDA矩阵运算通过，三片LLaVA训练初始化大小/SHA256均验收。既有CPU工程检查通过，但发布模型尚未前向：checkpoint的643个键不含多路径对齐模块参数，容器也缺源码引用的pixdlm_align_stages.pth，固定HF仓库仅发布一个主权重文件。缺失时源码走随机初始化，不能把该部署当作完整发布baseline；先核定权重来源或明确修改训练协议，不静默放行。未训练、评测或读test，见[加载核查记录](experiments/baseline_validation/experiment.md#6-运行记录)。
- 数据准备新增：4999张train/val图像逐文件SHA256无完全重复，但sequence_id不完整且共享采集元数据，不能称场景独立或无近重复。已生成待审604图训练/302图内部development整代理组清单及预填训练协议，原数据未改写、未开跑；用户只需审批，不填表。
- 独立离线前景评分器已补齐：13项合成边界检查及100例官方计数/公式对照通过，拒绝非有限值、错shape、缺项和重复ID；没有真实预测或指标，GT解码/坐标及推理接入仍待验收。
