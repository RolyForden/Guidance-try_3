# P1-参照关系绑定

## 当前问题

验证 PixDLM 在同类密集、参照关系可辨的 DRSeg 图像中是否存在目标实例混绑，以及简单位置提示是否足以解决。先补齐底座与实证锚，不承诺双角色模块有效。

## 当前判断

- 已知：用户选择优先验证 P1；公开评测分支存在标注回答条件输入，不能直接作为问题-only基线。
- 未知：底座复现量级、真实混绑频率、简单对照收益、准备与评测预算。
- 放弃条件：可靠基线不支持混绑假设，或匹配简单对照消除主要问题时，暂停本版参照绑定提案；不外推否定所有关系方法。
- 当前状态：用户已批准下载资产与准备环境，并要求避免GPU空耗；等待控制台切换无卡模式。本地已核下载版本/源端哈希，远端尚未安装或下载，未训练、未评测。
