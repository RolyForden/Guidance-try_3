# 路由 · 写作（读论文 / 审稿 / 写作）

> 开“写作”会话语时**先读这一份**；只做**指向**。底线见根 `AGENTS.md`。

| 必读 | 作用 |
|---|---|
| `docs/03_写作与投稿.md` | 读论文的术、审稿人视角、写作实操 |
| **论文底座** | 贡献 = 相对底座论文的改进；related work = 底座 + 近邻；实验 = 对底座 |

## 链路
```
实验（冻结记录 + 结果）──▶ 写作（本路由）──产出「稿件」──▶ 投稿
```
**上游输入**：底座档案（贡献基线）+ 实验结果；**贡献相对底座论文定义。**

实际读取项目 `idea/base_paper_<简称>.md` 与 `experiments/<实验名>/experiment.md` 及原始结果；稿件放项目 `paper/`，由项目 README 链接。证据不足退回对应实验补证，表达不足只改稿，不因写作问题自动重选题。

> 按 `routes/写作.md` 走：目标 = ___；**底座论文 = ___**；材料 = ___。
