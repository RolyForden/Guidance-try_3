# 路由 · 实验（设计 / 筛选 / 止损）

> 开“实验”会话语时**先读这一份**；只做**指向**。底线见根 `AGENTS.md`。

| 必读 | 作用 |
|---|---|
| `docs/02_实验设计与筛选.md` | 规则：20% 筛选、对照、失败定位、全量门槛 |
| `templates/experiment.md` | 模板：一次实验 = 一份冻结记录 |
| `templates/experiment_kickoff.md` | 流程：agent 自动起草、你只审批 |
| `docs/01_选题与立项.md`（锚节） | 若还没有锚，先立靶 |
| `docs/FAILURE_PATTERNS.md` | 别重踩的坑 |
| `docs/04_协作与Agent.md` | 派单 / 回传 / **交付包规格** |
| **论文底座** | baseline = 底座论文；先复现到量级；matched 预算 |

## 链路
```
选题（底座档案 + 锚）──▶ 实验（本路由）──产出「冻结记录 + 结果」──▶ 写作（routes/写作.md）
```
**上游输入**：项目 `idea/base_paper_<简称>.md`（已填档案，不是母本空模板）+ 锚 / H1；候选实验没有完整底座档案不许开跑。**底座复现例外**：使用已起草的底座档案与获批复现协议补齐档案 §1，不能顺带改方法或筛选候选；流程见 `templates/base_paper_kickoff.md`。

冻结记录放项目 `experiments/<实验名>/experiment.md`，结果与 `delivery/` 放该实验目录。实验失败先定位所在层；只有问题或底座被否定时才回选题。
