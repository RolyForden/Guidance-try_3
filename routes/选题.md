# 路由 · 选题（读文献找 gap / 动机 / 脉络）

> 开“选题 / 立项”会话语时**先读这一份**；只做**指向**。底线见根 `AGENTS.md`。

| 必读 | 作用 |
|---|---|
| `docs/01_选题与立项.md` | 选题规则：约束、找靶、锚、**论文底座（参照锚）**、框架/轴、gap 锋利、设计方法 |
| `templates/base_paper.md` | **产出**：底座档案（读透一篇论文的物证） |
| `templates/base_paper_kickoff.md` | 流程：agent 自动起草底座档案、你只审批 |
| `docs/选题gap审计规则.md` | 文献矩阵 / 查重时的 Gap 合法性审计 |
| `docs/FAILURE_PATTERNS.md` | 已证实的失败模式 |
| `docs/fields/` | 领域 Frontier Map |

## 链路（本阶段在整条链上的位置）
```
选题（本路由）──产出「底座档案 + 窄问题 + 锚」──▶ 实验（routes/实验.md）──产出「冻结记录 + 结果」──▶ 写作（routes/写作.md）
   ▲                                                                                                   │
   └──────────── 仅问题或底座不成立时退回选题；实现失败留在实验、证据缺口退回对应实验 ◀─────────────────┘
```

底座复现是选题阶段的获批准备动作：先草稿、再审批复现、再补齐档案，不要求运行前已有自己的复现数字。写作表达问题只改稿；环境错误先修环境，不自动重选题。重大方向改变仍由用户决定。

## 起手式
> 按 `routes/选题.md` 走：目标 = ___；**论文底座（1–2 篇 + 其 limitation）= ___**；已有材料 = ___。
> 底座档案：agent 走 `templates/base_paper_kickoff.md` 自动起草 `templates/base_paper.md`，你只审批。
